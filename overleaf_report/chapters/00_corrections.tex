One finding in this report contradicts a claim made earlier in the same
project: a decomposition of the verification-latency effect, withdrawn
after the contrast was found not to be identified. The superseded claim
is stated together with the design error that produced it, rather than
removed (\S{}5.3).

This is deliberate. The correction is part of the evidence --- it
records which conclusions survived contact with a control and which did
not, and the control that overturned it had been built for a different
purpose.
